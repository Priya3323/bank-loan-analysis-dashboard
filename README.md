# Bank Loan Analysis & Risk Assessment Dashboard
![Dashboard Preview](dashboard_preview.png)

## Project Overview
An interactive Microsoft Excel dashboard created to analyze loan applications, approval rates, customer risk levels, and loan trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning Functions
- KPI Cards

## Key Metrics
- Total Applications: 1,200
- Approval Rate: 47.33%
- Avg Loan Amount: 372.90

## Dashboard Insights
- Loan Approval Distribution
- Approval by Property Area
- Income Group Comparison
- Customer Risk vs Loan Status

## Features
- Dynamic KPI Cards
- Interactive Slicers
- Real-time Filtering
- Business-focused Dashboard Design
